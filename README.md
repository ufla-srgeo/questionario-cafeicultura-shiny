# questionario-cafeicultura-shiny
Desenvolvido no âmbito do Laboratório de Sensoriamento Remoto e Geoprocessamento da Universidade Federal de Lavras (UFLA), este repositório contribui para o aprimoramento contínuo de ferramentas de Geointeligência aplicadas à cafeicultura, unindo a validação acadêmica de usabilidade ao desenvolvimento de soluções open-source para o setor agrária.
