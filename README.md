Este repositório contém a interface web responsiva para a coleta de dados e avaliação técnica do **Dashboard Interativo em R/Shiny para Manejo e Tomada de Decisão na Cafeicultura de Precisão**.

O objetivo principal desta pesquisa é mensurar a experiência do usuário (UX), a clareza da comunicação cartográfica e a aplicabilidade agronômica da ferramenta na gestão de talhões cafeeiros.

---

## 📋 Sobre a Pesquisa

O dashboard avaliado foi desenvolvido para integrar dados de Geoprocessamento e Sensoriamento Remoto aplicados à cafeicultura, permitindo análises espaço-temporais e comparações multicritério entre diferentes áreas de cultivo.

A avaliação busca mensurar:
* **Facilidade de Navegação e Usabilidade:** Fluidez da interface e clareza nos controles do sistema.
* **Comunicação Cartográfica:** Efetividade dos mapas interativos, simbologia temática e janelas de informação (*pop-ups*).
* **Análise Multicritério:** Clareza dos gráficos de radar para tomada de decisão no manejo do cafezal.
* **Demandas do Setor:** Identificação de novos recursos prioritários (ex.: índices de vegetação como NDVI, dados de relevo e estimativa de safra).

---

## 🛠️ Arquitetura da Solução

A estrutura de coleta de dados foi projetada para ser leve, assíncrona e acessível a partir de qualquer dispositivo:

* **Frontend:** HTML5, CSS3 responsivo e JavaScript nativo (Fetch API).
* **Hospedagem Frontend:** GitHub Pages (`ufla-srgeo.github.io`).
* **Backend e Armazenamento:** Google Apps Script integrado ao Google Sheets para estruturação e persistência dos dados em tempo real.
